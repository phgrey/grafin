# Calculus: Rates of Change and Derivatives

## Definition of the Derivative

The derivative of a real function $f(x)$ measures the sensitivity to change of the function value with respect to a change in its argument. Formally defined as the limit of a difference quotient:

$$f'(x) = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h}$$

If this limit exists, the function $f$ is said to be differentiable at $x$.

## Fundamental Theorem of Calculus

The Fundamental Theorem of Calculus establishes the connection between differentiation and integration. It asserts that integration and differentiation are inverse operations:

$$\int_{a}^{b} f(x) \, dx = F(b) - F(a)$$

where $F'(x) = f(x)$.
